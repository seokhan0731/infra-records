# infra-records

로컬이 아닌 실제 서버에 배포하고 운영한 기록을 정리한다.

콘솔 조작 순서가 아니라 **무엇을 판단했고 어디서 막혔는지**를 쓴다.

---

## 기록의 기준

| 쓴다           | 안 쓴다            |
|--------------|-----------------|
| 판단이 있었던 것    | 검색하면 나오는 표준 절차  |
| 막혔던 것        | 문서에 적힌 대로 따라간 것 |
| 기본값과 다르게 한 것 | 결과만 있고 근거가 없는 것 |

**확인한 것과 확인하지 않은 것을 구분해 적는다.**

---

#### NCP 인프라 구축 기록에서 다룬 것

- SSH 무차별 접속 7,781건 -> 공개키 전환 이후 0건
- 장시간 데이터 적재 전, smoke test로 컨테이너 기동 실패 원인 2건 선발견
- 팀 명세서 오류 2건 지적 (chown -R · .env 경로 누락)
- 컨테이너 실행 UID 가 이미지마다 달라 bind mount 소유권을 이미지에서 확인 (neo4j 7474)
- 사고가 없었던 이유가 조치가 아니라 조건이었다는 점
